# AI-Chat Roadmap (Gomin Messenger)
**Дата:** 26 травня 2026 року
**Моделі:** Gemini 3 Pro, Gemini 3 Flash, Gemma 4
**Контекст:** 250k+ токенів

## Етап 1: Дезінфекція та Ребрендинг (Gomin Cleanup)
- [ ] Повна заміна тексту `Cherrygram` -> `Gomin` у ресурсах та коментарях.
- [ ] Очищення `Constants.kt` від старих посилань (Arslan, Cherrygram Channel).
- [ ] Видалення залишків іконок або графіки старого мода.

## Етап 2: Інтеграція AI-двигуна (Gemini 3 & Gemma 4)
- [ ] Фільтрація списку моделей в `ApiClient.java` (тільки Gemini 3 Pro/Flash та Gemma 4).
- [ ] Додавання підтримки кастомного Base URL для Groq/OpenRouter.
- [ ] Підготовка системної інструкції (2 листи А4) у `assets/prompts/`.

## Етап 3: Фіча "Щит" (Contextual Analysis)
- [ ] Кнопка "Щит" у верхній панелі `ChatActivity`.
- [ ] Логіка **Hard Reset** сесії при кожному натисканні (чиста історія для кожного чату).
- [ ] Викачування 500 останніх повідомлень через `MessagesStorage`.
- [ ] Вивід аналізу маніпуляцій/газлайтингу (на основі 2-х листів системного промпту) в `BottomSheet`.

## Етап 4: Gomin AI Assistant (Virtual Local Chat)
- [ ] Створення віртуального `dialogId` для локального АІ-чату.
- [ ] Кнопка **"Новий чат"** для повного обнулення історії та пам'яті.
- [ ] Локальне збереження історії в SQLite.
- [ ] Підготовка архітектури під Knowledge Graph та RAG (пам'ять).

## Етап 5: Промпт-Менеджмент
- [ ] Винесення всіх інструкцій в `assets/prompts/*.txt`.
- [ ] Можливість редагування системної інструкції через налаштування.
