## ⚡ Gomin Speed Engine: Безпрецедентна швидкість

Мережевий стек оригінального Telegram розроблявся під середньостатистичні глобальні стандарти. Ми переосмислили цю архітектуру, створивши власне ядро передачі даних — **Gomin Speed Engine**, яке максимізує пропускну здатність на будь-якому з'єднанні.

* **Boost Extreme (Активовано за замовчуванням)** 🚀
  Для завантаження великих файлів (відео, архівів, RAW-фото) Гомін сегментує їх на масивні блоки по **1 МБ** і скачує паралельно через **12 високошвидкісних TCP-потоків** (проти стандартних 4 потоків по 128 КБ). Це забезпечує прискорення у 2-3 рази на сучасних мережах (Wi-Fi 6, 5G).
* **Extreme Upload (Прискорене вивантаження)** ⚡
  Буфер відправлення збільшено до **512 КБ**. Ваші медіафайли та важкі документи передаються миттєво, мінімізуючи затримки обробки на рівні сокетів.
* **Режим "Укриття" (Shelter Mode)** 🛡️
  Створений спеціально для екстремальних умов українських реалій. У зонах зі слабким або нестабільним покриттям (укриття, метро, підвали) алгоритм перебудовує трафік в один стабільний потік мікро-пакетів по **32 КБ**. Це гарантує доставку повідомлень і файлів без постійних таймаутів та обривів з'єднання.

## 🧠 Екосистема Штучного Інтелекту (Gomin AI & Ментальний щит)

Ми інтегрували передову мультимодальну модель **Google Gemini** безпосередньо в ядро месенджера, забезпечивши нативну та глибоку взаємодію.

### 🤖 Нативний ШІ-асистент Gomin AI
Інтелектуальний віртуальний співрозмовник, вбудований у звичний інтерфейс чату. 
* **Локальне перехоплення:** Працює через емуляцію нативного чату, не надсилаючи жодних даних на сервери Telegram.
* **Глибока інтеграція:** Підтримує статуси "друкує...", відображає стандартні бабли повідомлень та дозволяє легко змінювати мовну модель (Gemini 2.5 Flash, 3.1 Pro тощо) прямо з меню чату.

### 🛡️ Ментальний щит (Gomin Shield)
Ваш особистий цифровий психолог і захисник у комунікації.
* **Миттєвий аналіз:** Запускається в один клік у будь-якому приватному чаті, аналізуючи до 1500 останніх повідомлень.
* **Структурований звіт:** Виявляє токсичність, приховані мотиви та газлайтинг, надаючи детальний розбір "червоних прапорців" (🚩) та стратегій захисту.
* **Безшовна передача контексту:** Перейдіть від звіту безпосередньо в діалог з Gomin AI — асистент вже матиме повний контекст розмови для надання порад або допомоги у формулюванні відповіді.

### 🎙️ Live Audio Dictation (Нативне ШІ-диктування)
Революція в голосовому введенні за допомогою низькозатримкових WebSocket-стрімів.
* Замість класичного розпізнавання тексту, аудіопотік обробляється нейромережею **Gemini Multimodal Live API** у реальному часі.
* Нейромережа автоматично виправляє граматику, ідеально розставляє розділові знаки та розуміє контекст сказаного, миттєво вставляючи готовий ідеальний текст у поле введення.

## 👻 Gomin Ghost Mode: Абсолютна приватність

Твоя цифрова присутність має належати тільки тобі. Гомін пропонує чотирирівневу систему захисту приватності:

* **Захист від читання (Unread Guard):** Читайте будь-які повідомлення, залишаючи їх непрочитаними для відправника, доки ви самі не вирішите відповісти.
* **Маскування активності:** Повністю приховує статуси "друкує..." або "записує голосове...".
* **Прихований онлайн:** Спілкуйтеся та читайте повідомлення, залишаючись для всіх зі статусом "не в мережі" (офлайн).
* **Невидимі Stories:** Переглядайте історії контактів абсолютно анонімно, без фіксації у списках переглядів.
* **🛡️ Анти-видалення:** Повідомлення залишаються у вашому кеші навіть після того, як співрозмовник видалив їх "для всіх". Такі повідомлення елегантно позначаються іконкою 🗑️, зберігаючи повний контекст розмови.

## 🚨 Інтегрована Повітряна Тривога

Створено з думкою про безпеку українців. Система сповіщення інтегрована прямо в ядро програми.
* **Надійний парсинг:** Використовує власний виділений сервер для аналізу офіційних каналів з тривогами.
* **Локальне налаштування:** Дозволяє обрати конкретну область чи територіальну громаду.
* **Червоний режим небезпеки:** Найголовніша фішка — під час активної тривоги заголовок (header) додатка повністю зафарбовується в попереджувальний червоний колір, миттєво привертаючи увагу.
* **Кастомні аудіосповіщення:** Гучна сирена на початок та заспокійливий сигнал на відбій. Наявний режим локального тестування сигналу.

## 🧪 Запуск та Налаштування

Щоб активувати розширені функції, виконайте наступні кроки у встановленому додатку:

1. **Ініціалізація ШІ:** 
   Перейдіть у **Налаштування** -> **Налаштування Gomin AI**, введіть ваш Google Gemini API Key (безкоштовно доступний у Google AI Studio) та оберіть бажану модель.
2. **Виклик Асистента:** 
   На головному екрані діалогів натисніть FAB-кнопку (іконка іскорок ✧), щоб відкрити чат з Gomin AI.
3. **Live Dictation:** 
   У діалозі затисніть кнопку прикріплення (скріпка) для старту потокової транскрипції голосу в текст.
4. **Використання Ментального щита (Gomin Shield):** 
   У будь-якому приватному чаті натисніть на іконку щита (🛡️) у верхньому меню для глибокого аналізу поведінки співрозмовника.
5. **Налаштування тривоги:** 
   Перейдіть у **Налаштування** -> **Налаштування Gomin** -> **Повітряна тривога 🚨**, оберіть ваш регіон і натисніть "Тест сигналу".

## 🛠️ Збірка проєкту для розробників

Гомін використовує систему збірки Gradle та базується на потужній архітектурі Android-клієнта.

1. **Клонування репозиторію:**
   ```bash

   ```
2. **Відкриття в Android Studio:**
   Синхронізуйте проєкт з Gradle-файлами.
3. **Локальна компіляція (Standalone Release):**
   ```bash
   ./gradlew :TMessagesProj_AppStandalone:assembleAfatStandalone
   ```
