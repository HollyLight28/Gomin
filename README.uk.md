## 🏛️ Історія створення: Як народився «Гомін»

Вся ця історія почалася не в тихих кабінетах корпорацій, не з маркетингових звітів чи бізнес-планів. Вона почалася з одного-єдиного слова, в яке неможливо було не закохатися — **«Гомін»**. 

Це слово пахне свободою, гудінням українських міст, теплими вечорами та живим відлунням людських голосів. Коли народилася ця назва, стало зрозуміло: вона занадто крута, щоб просто зникнути чи порости пилом на звалищі забутих ідей. Заради неї варто було пройти через усі кола пекла мобільної розробки, розібратися у мільйонах рядків заплутаного C++ та Java-коду оригінального Telegram, витримати тижні безсонних ночей і створити щось справжнє.

В Україні досі не було свого власного Telegram-клієнта з національним характером та душею. Більшість сторонніх додатків — це або перевантажені рекламою монстри, або дитячі іграшки з купою непотрібних блискіток. 

**Гомін** — це спроба зробити Telegram чистим, блискавично швидким і по-справжньому нашим. Додатком, який створюється не заради комерції, а на чистому ентузіазмі, драйві та любові до своєї справи. Створений для людей, які цінують простоту, швидкість і хочуть відчувати свій рідний вайб у кожному дотику до екрана.

## 💎 Наші головні Killer Features (Те, що робить Гомін унікальним)

Ми не будемо сипати красивими маркетинговими фразами про «хмарні інновації». Гомін створений розробником для реального життя, реальних мереж та реальних потреб людей в Україні. Ось наш золотий набір кілер-фіч:

### ⚡ 1. Екстремальний мережевий движок (Gomin Speed Engine)
Це серце нашого додатка. Стандартний Telegram оптимізований під консервативні світові стандарти мобільного зв'язку, але ми вивели швидкість на абсолютно новий рівень.

* **Режим Boost Extreme (Активовано за замовчуванням)** 🚀:
  Коли ти завантажуєш важке відео, великий архів чи оригінальні фото, Гомін ділить завантаження на гігантські блоки по **1 МБ** і скачує їх паралельно через **12 одночасних TCP-потоків** (у звичайному Telegram це лише 4 потоки по 128 КБ). Це дає реальне **прискорення у 2-3 рази** на швидкісному домашньому Wi-Fi чи 5G!
* **Прискорене вивантаження (Extreme Upload)** ⚡:
  Ми збільшили буфер відправки великих файлів до **512 КБ** (замість стандартних 128 КБ). Твої медіа та документи летять у чат миттєво, без зайвих секунд очікування на обробку сокетів.
* **Режим "Укриття" (Slow Network Mode)** 🛡️:
  Наша сувора оборонна реальність. Коли ти перебуваєш у підвалі, метро, бомбосховищі або в зоні з украй слабким покриттям, де мережа ледве дихає — цей режим рятує життя. Він змушує додаток стабільно вивантажувати медіа в один-єдиний потік мікро-пакетами по **32 КБ**, запобігаючи постійним обривам зв'язку та таймаутам сокетів.

### 🖤 2. Ексклюзивний дизайн Gomin Black Edition & Monet
Ми витратили десятки годин, щоб вилизати інтерфейс до ідеалу та подарувати тобі преміальний візуальний досвід:
* **Справжній OLED Black**: Ніяких сірих напівтонів. Глибокий, чистий чорний колір, який виглядає надзвичайно дорого, розвантажує очі під час нічного читання та суттєво економить заряд твого смартфона.
* **Гармонія кольорів Monet**: Ми вилікували стрибки кольорів при переходах між папками та чатами. Усі акценти м'яко адаптуються під колірну палітру твоєї системи Android 12+, створюючи єдиний преміальний стиль.
* **Елітна Scaled ActionBar**: Ми побороли стандартне обмеження розміру шрифту заголовків Telegram. Замість стиснутого 20sp, назва **«Гомін»** гордо височіє у стабільному, великому масштабі **24sp**, випромінюючи статус та впевненість додатка.

### 👻 3. Чотирирівневий режим невидимки Gomin Ghost
Твоя приватність — це твій особистий простір. Залишайся в тіні, коли це потрібно:
* **Захист від галочок (Unread Guard)**: Читаєш повідомлення, а для співрозмовника вони залишаються непрочитаними, поки ти сам не вирішиш відповісти або синхронізувати чат.
* **Маскування статусу друку**: Повністю приховує плашку "друкує..." або "записує голосове...". Думайте над відповіддю без зайвого поспіху.
* **Невидимий перегляд Stories**: Дивись чужі сторіз абсолютно анонімно, без жодних слідів у списках перегляду.
* **Прихований онлайн**: Спілкуйся в додатку, залишаючись для всіх у статусі "офлайн".

### 🧠 4. Інтегровані ШІ-функції (Gomin AI)
Гомін підтримує роботу з передовим штучним інтелектом.
* Якщо ти маєш свій **Gemini API Key**, ти можеш просто вставити його в налаштуваннях додатка. Це відкриє доступ до вбудованих інтелектуальних ШІ-функцій: розумного чат-асистента Gemini прямо в списку чатів та можливості розшифровувати будь-які голосові повідомлення на льоту!

### 🎯 5. Унікальні авторські фішки та ергономіка
* **Тумблер №16: "Видалити для всіх" за замовчуванням** 🗑️:
  Більше ніякого геморою з постійним натисканням цієї бісової галочки при видаленні повідомлень, яка всіх так дратує. Просто видалив — і знаєш, що воно видалилося в усіх. Чисто, швидко і надійно.
* **Чистий ергономічний пошук**:
  Ми перенесли поле пошуку зверху вниз і прибрали зайве візуальне поле пошуку, щоб екран залишався чистим та елітним. Це наша авторська фішка для зручного керування однією рукою!
* **Крафтові шрифти**:
  Замість стандартних системних шрифтів ми використовуємо унікальні шрифти (на кшталт **Manrope**), які роблять відображення тексту м'яким, гармонійним та комфортним для очей при тривалому читанні.
* **Жодного рекламного сміття**:
  Ми повністю вирізали спонсорські канали від безкоштовних проксі-серверів та вичистили аналітичні трекери. Гомін працює швидше і не збирає твої дані.

## 🛠️ Як зібрати проект локально

Якщо ти розробник і хочеш скомпілювати Гомін самостійно:

1. **Клонуй репозиторій**:
   ```bash
   git clone https://github.com/HollyLight28/Gomin.git
   ```
2. **Відкрий в Android Studio** та дочекайся Gradle-синхронізації.
3. **Збери автономну версію** командою в терміналі:
   ```bash
   ./gradlew :TMessagesProj_AppStandalone:assembleAfatStandaloneDebug
   ```
