# 🔊 Гомін — Український месенджер преміум-класу

**Гомін (Gomin)** — це висококласний месенджер без зайвого візуального шуму, створений для тих, хто цінує преміальну естетику, максимальну швидкість та абсолютну конфіденційність. Побудований на глибоко оптимізованому ядрі Telegram, Гомін перетворює звичне спілкування на професійне та надихаюче середовище з вільною українською душею.

---

## 🏛️ Візія продукту

Гомін повністю відмовляється від хаотичної та складної кастомізації, притаманної більшості сторонніх клієнтів, на користь **елегантного мінімалізму в стилі WhatsApp**. Ми переконані, що професійний інструмент має працювати бездоганно одразу «з коробки». Завдяки інтеграції екстремальних налаштувань мережі, витончених пружних анімацій та безкомпромісного захисту приватності безпосередньо в код, Гомін звільняє вас від системної рутини, дозволяючи зосередитися на головному — безпечному та елітному спілкуванні.

---

## ✨ Фірмові Killer-фічі

### ☁️ Gomin Drive (100% нативна персональна хмара)
Telegram під капотом є геніальним безлімітним хмарним сховищем, але його стандартний інтерфейс ховає цей потенціал. **Gomin Drive** розкриває його на повну силу без жодних складних хештегів чи костилів:
* **Доступ в один дотик**: Спеціальна витончена кнопка-хмарка у верхній панелі чату «Збережене» миттєво відкриває ваш персональний диск.
* **Абсолютна інтеграція**: Працює на базі нативного екрана `MediaActivity` (Shared Media), що гарантує 100% плавність.
* **Автоматичне сортування**: Всі ваші файли, документи, музика, лінки та голосові повідомлення автоматично розкладаються по вкладках із нативним швидкісним пошуком Telegram.
* **Швидкість та стиль**: Інтерфейс повністю підтримує вашу активну тему оформлення та літає зі швидкістю оригінального додатка.

### 🧠 Помічник Gomin AI (Стабільна інтеграція Gemini)
Забудьте про незграбні сторонні вікна поверх екрана. Помічник Gomin AI інтегрований безпосередньо в нативний, ультра-чуйний екран чату `ChatActivity`:
* **Нативний досвід**: ШІ-асистент відображається як віртуальний локальний діалог у загальному списку чатів, підтримуючи фірмові анімації бульбашок повідомлень, маркдаун-розмітку, виділення тексту та медіафайли.
* **Робота з контекстом розмов**: Торкніться скріпки прикріплення файлів 📎 або меню зверху та оберіть «Підключити контекст чату». Вкажіть будь-який діалог, і Gomin AI проаналізує останні 150 повідомлень, щоб зробити вижимку розмови, виділити головні тези чи запропонувати варіанти відповідей.
* **Локальна безпека**: Увесь діалог з ШІ зберігається виключно у вашій локальній базі даних SQLite і захищений від будь-якого зовнішнього трекінгу.

### ⚡ Gomin Speed Boost (Екстремальне багатопотокове скачування)
Насолоджуйтеся неймовірною швидкістю передачі медіа без потреби розбиратися в технічних тонкощах:
* **Екстремальне завантаження**: Завдяки вбудованому движку багатопотокового скачування (режим `BOOST_EXTREME` активовано завжди) швидкість завантаження файлів та медіа витискає максимум з вашого інтернет-каналу.
* **Прискорене вивантаження**: Оптимізовані мережеві буфери дозволяють відправляти великі документи та відео високої роздільної здатності за лічені секунди.
* **Ощадливість**: Налаштування збалансовані так, щоб забезпечувати пікову швидкість без перегріву процесора чи надмірного розряду батареї.

### ✍️ Брендована типографіка та чистий інтерфейс
* **Вишукана типографіка**: Вбудовані кастомні шрифти преміум-класу, спеціально оптимізовані для тривалого та комфортного читання з мобільних екранів.
* **Лаконічні налаштування**: Ми прибрали сотні дратівливих дрібних перемикачів, що перевантажували інтерфейс і викликали збої, залишивши лише критично важливі опції для вашого спокою.

## 🛠️ Технічна архітектура

* **Базове ядро**: Telegram for Android (Глибоко оптимізована версія)
* **Платформа движка**: Cherrygram Framework
* **Мови програмування**: Kotlin (54%), Java (42%), C++ (JNI для шифрування та високошвидкісних операцій ядра)
* **Інтеграція ШІ**: API Google Gemini через безпечні локальні запити
* **Безпека**: Повна відсутність аналітичних трекерів, обов'язкова перевірка сертифікатів TLS, блокування спонсорської реклами проксі.

## 🚀 Встановлення та розробка

Для локальної збірки Гоміну на вашому комп'ютері:

1. **Клонуйте репозиторій**:
   ```bash
   git clone https://github.com/HollyLight28/Gomin.git
   ```
2. **Відкрийте в Android Studio**:
   Імпортуйте кореневу директорію проєкту. Зачекайте завершення Gradle-синхронізації.
3. **Зберіть автономну (Standalone) версію**:
   Виконайте команду в терміналі для створення налагоджувального пакету:
   ```bash
   ./gradlew :TMessagesProj_AppStandalone:assembleAfatStandaloneDebug
   ```
