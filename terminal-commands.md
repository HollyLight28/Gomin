# Корисні термінальні команди

Цей файл містить перелік найчастіше використовуваних термінальних команд для розробки, збірки та управління цим проектом. 

> **Важливо:** Ваш проект використовує специфічні "флейвори" (flavors), зокрема `afat`, тому стандартні команди Gradle тут не підійдуть. Використовуйте саме ті, що наведені нижче!

> **Примітка для Windows:** Для запуску команд використовується `.\gradlew` (або `gradlew.bat`). Для Mac/Linux це `./gradlew`.

## 🛠 Збірка проекту (Gradle)

### 1. Очищення проекту
```bash
.\gradlew clean
```
**Опис:** Видаляє папку `build/` з попередніми результатами компіляції. Допомагає, коли треба зібрати проект "з чистого аркуша" після помилок кешу або перед важливою релізною збіркою.

### 2. Збірка Debug-версії (для тестування)
```bash
.\gradlew assembleAfatDebug
```
**Опис:** Створює APK-файл для дебагу (відлагодження) з флейвором `afat`. Ідеально підходить для розробки, перевірки на емуляторі або власному телефоні.

### 3. Збірка Standalone Release (APK для прямого розповсюдження)
```bash
.\gradlew assembleAfatStandalone
```
**Опис:** Створює готовий релізний APK-файл (`standalone` збірка), який компілюється модулем `TMessagesProj_AppStandalone`. Цей файл можна встановлювати напряму на будь-який пристрій (наприклад, поширювати через Telegram чи свій сайт). *Після збірки цей файл автоматично копіюється на ваш Робочий стіл у папку Cherry/Stable (згідно з налаштуваннями у build.gradle).*

### 4. Збірка для Google Play (Android App Bundle - AAB)
```bash
.\gradlew bundleAfatRelease
```
**Опис:** Створює оптимізований файл `.aab` (Android App Bundle), компілюється модулем `TMessagesProj_App`. **Цей файл призначений виключно для завантаження в Google Play Console**. *Після успішної збірки він також автоматично копіюється на ваш Робочий стіл у папку Cherry/Stable.*

## 📱 Встановлення на пристрій

### 5. Швидка збірка та встановлення (Debug)
```bash
.\gradlew installAfatDebug
```
**Опис:** Збирає Debug-версію додатка і автоматично встановлює її на підключений пристрій (через USB) або на запущений емулятор. Дуже зручно, щоб не шукати APK вручну.

## 🌳 Робота з Git (Версіювання коду)

### 6. Перевірка статусу файлів
```bash
git status
```
**Опис:** Показує, які файли були змінені, створені або видалені з моменту останнього збереження (коміту).

### 7. Додавання всіх змін до коміту
```bash
git add .
```
**Опис:** Додає **всі** поточні зміни в проекті до підготовки для збереження. 

### 8. Збереження змін (Коміт)
```bash
git commit -m "Опис ваших змін"
```
**Опис:** Зберігає всі додані зміни з певним повідомленням (наприклад, "Виправив баг").

### 9. Відправка та завантаження змін
```bash
git push
git pull
```
**Опис:** `push` відправляє ваші локальні зміни на віддалений сервер (наприклад GitHub), а `pull` стягує останні зміни з сервера до вас.

## 🔍 Інші корисні команди

### 10. Перегляд дерева залежностей
```bash
.\gradlew app:dependencies
```
**Опис:** Виводить список усіх бібліотек, які використовує ваш проект. Допомагає при конфліктах версій.
